# Marketing Campaign Performance & ROI Analysis

## Overview

Analyzed marketing campaign performance using Python, MySQL, and Power BI to identify high-performing campaigns, inefficient budget allocation, and conversion trends.

The project focused on solving real business problems instead of only building dashboards.

---

# Tools Used

* Python
* MySQL
* Power BI

---

# Project Workflow

* Cleaned and prepared campaign data using Python
* Performed KPI and business analysis using MySQL
* Built an interactive Power BI dashboard for visualization and reporting

---

# Business Questions Answered

* Which campaigns generated the highest ROI?
* Which channels drained the most marketing budget?
* Which campaigns failed to deliver expected results?
* Which platforms showed stronger engagement and conversion performance?

---

# Key Insights

* Total revenue exceeded **$15B** with overall positive campaign performance.
* Email campaigns generated the strongest ROAS.
* Facebook campaigns showed the weakest return on ad spend.
* Some campaigns produced high traffic but weak conversion quality.
* Major cities showed stronger audience engagement and campaign activity.

---

# Recommendations

* Reallocate budget toward high-ROAS campaigns
* Reduce spending on underperforming channels
* Improve targeting and landing page optimization for weak-converting campaigns
* Monitor campaign efficiency using ROAS and conversion metrics instead of clicks alone
